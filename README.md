# Event Planner Dashboard

A lightweight, full-stack web application built with PHP and MySQL that allows users to securely log in, create custom events, and track them via a personalized dashboard with live countdown timers.

## 🚀 Features
* **Secure Authentication:** User registration and login utilizing PHP sessions and secure password hashing.
* **Personalized Dashboard:** A private hub displaying only the events created by the logged-in user.
* **Event Management:** Create events with specific details including Event Type, Host, Venue, Date, Time, and Description.
* **Live Countdown Timers:** Custom JavaScript timers that calculate the exact days, hours, minutes, and seconds until an event begins.
* **Responsive UI:** Clean, modern interface designed for both desktop and mobile viewing.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (PDO)
* **Database:** MySQL
* **Environment:** Laragon / XAMPP
